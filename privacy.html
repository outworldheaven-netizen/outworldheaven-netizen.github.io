Scope and operator

This policy describes AI Channel Autopilot, a personal desktop application operated by the owner of the Signal & Sense YouTube channel. It also explains the limited information website you are reading. The application is currently a prototype for the operator’s own use; other people cannot create an account here.

Privacy contact: outworldheaven@gmail.com.

Use and sharing

The local application uses Google and YouTube information only to connect the authorised channel and perform its owner-approved upload and scheduling workflow. It does not sell Google user data, use it for targeted advertising, or use it to train a general-purpose AI model.

The current production adapters send topic prompts, public-source evidence and scripts to OpenAI and Anthropic for drafting and review; search queries to Tavily; generated visual prompts and images to Runway; and narration or generated audio to the configured voice and transcription providers. OpenAI is the default voice provider. ElevenLabs is optional if the operator explicitly configures it.

The current code does not send Google OAuth tokens, YouTube account responses or upload-state responses to those AI providers. Completed media and its publishing metadata are transmitted to YouTube. Each external provider processes the information it receives under its own service terms and privacy arrangements, which may involve processing outside the operator’s country.

Use and onward transfer of data obtained from Google APIs are limited to the disclosed application functions and the applicable Google API Services User Data Policy, including its Limited Use conditions.

Local storage and retention

The prototype saves credentials in local configuration and token files, and saves production records in local job folders and a local database. It restricts file permissions where the operating system supports that mechanism; it does not itself encrypt these files. Device encryption, access controls and backup or folder-sync settings are controlled by the operator.

If the working folder is inside a synced location, such as OneDrive, that service may also store a copy under the operator’s settings. Local storage does not mean that a synchronised copy cannot exist.

Tokens remain available locally while the connection is needed. The current prototype has no automatic retention or deletion sweep. The operator must remove unneeded working data and, for retained YouTube API responses other than permitted authorisation tokens, refresh or remove those responses within 30 days. Production content created by the operator, such as scripts and rendered video files, is managed separately from YouTube API response data.

Support correspondence is kept only as long as needed to handle the request and any applicable record-keeping obligations.

Disconnecting and deleting data

  1. Stop the local worker to prevent further production and uploads.
  2. Remove AI Channel Autopilot’s access in your Google Account connections.
  3. Delete the local Google token file and any retained YouTube upload-state or API-response data, including copies in backups or synced folders. The default token file is secrets/youtube_token.json; upload state is saved in job folders.

The operator can also remove local API keys and generated project data that are no longer needed. Revoking Google access does not itself erase local files. Deleting local files does not delete videos already stored on YouTube or cancel a publication already scheduled there; manage those in YouTube Studio.

For a deletion request concerning data held by the operator, use the contact address above. The operator will remove relevant locally held YouTube user data as soon as possible and within seven calendar days of a valid deletion request. This is an operator-handled procedure, not an automated function in the current prototype.

This website and third parties

This information site has no visitor accounts, payment forms, embedded video players, advertising scripts or site-authored analytics. Its pages do not set cookies or use browser storage. The hosting service may process connection and security information, including IP addresses; private preview hosting may also require its own account sign-in.

On GitHub Pages, GitHub logs visitors’ IP addresses for security. See the GitHub Privacy Statement. A private preview served through ChatGPT Sites is also subject to the host’s privacy policy. External links take you to other providers’ services.

The desktop application uses YouTube API Services. Google’s handling of information is described in the Google Privacy Policy.

Changes and questions

The date at the top identifies this version. The operator should update this policy before changing the way the application handles Google or YouTube data, and obtain any additional consent required for new uses. Contact the operator with questions or concerns.
