What it does

A desktop workflow for one channel.

Evidence first

Public-source research supports each episode. A separate AI provider reviews claims and the script against the collected evidence.

Media production

AI services provide illustrations, short clips and narration. Local tools assemble the video, captions and thumbnail.

Channel connection

Google authorisation connects the owner’s YouTube channel. The program checks the channel identity before sending a completed video.

Owner control

The owner configures the topic brief, budget and schedule. Stopping the local worker stops future production; access can be revoked through Google.

Current status: a personal prototype undergoing setup and testing. Uploading and scheduling depend on completed configuration and Google’s applicable requirements. This site provides information; it is not a public sign-up or hosted video-generation service.

YouTube access

Permission with a purpose.

AI Channel Autopilot uses YouTube API Services to identify the authorised channel, upload a completed video, set its thumbnail, check processing and request a publication time.

The current Google permission also covers broader video and comment management. The prototype uses it for the upload workflow described here; it does not implement comment moderation or video deletion.

Google credentials and channel access are handled by the local program. This information website does not ask visitors to sign in to Google or enter API keys.
